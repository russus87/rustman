Catene di chiamate, come un grafo

Trascina le richieste su un canvas, collegale e definisci i rami: «continua solo se lo status è 200», altrimenti prendi un'altra strada. L'esecuzione segue il grafo — con branch e merge reali.

  • ✓Rami condizionali sugli archi (status, JSON, variabili).
  • ✓Cattura di variabili dalle risposte e passaggio ai passi successivi.
  • ✓Stesso motore nella UI e nella CLI headless per la CI.

CLI & CI

Esegui le suite in pipeline

L'eseguitore headless rustman run lancia collezioni e flussi, valuta le asserzioni ed esce con codice ≠ 0 al fallimento. Report JUnit e HTML inclusi. 

# esegui un flusso a nodi e genera il report JUnit
rustman run ./workspace --chain "Flusso Branch" --junit report.xml

# test di carico con gate SLO (p95 e error-rate)
rustman perf ./workspace --request demo/get.json \
  --duration 30 --concurrency 20 --rps 50 --max-p95 200 --max-error 1
